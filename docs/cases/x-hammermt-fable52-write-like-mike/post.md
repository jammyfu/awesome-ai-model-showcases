## Wiki summary (paraphrase, not the original post)

简介　Michael Taylor 比较了四种写作技能做法，并用自己的真实文章做留出评估。他报告经过调优的方案在其中一组对照里胜率最高约 95%，一次生成的技能反而输给了无技能对照。

证据与边界　Every 将它列在 Fable 5.2 试用成果中。图表比较的是技能方案，95% 指作者设定下的留出结果。

## Original post text

Write Like Mike Experiment

Four ways to build a skill that writes like me, judged blind against my real posts.

Tuning beats writing: tuned skills won up to 95% of held-out posts, while a skill Claude wrote in one shot lost to having no skill at all.
