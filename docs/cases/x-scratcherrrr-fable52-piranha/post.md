## Wiki summary (paraphrase, not the original post)

简介　三维鱼会张口、展开鱼鳍、露出骨骼和胃部。作者把整段拆解做成一支约 20 秒的动画。

证据与边界　鱼的基础模型由 Opus 5.5 用 Three.js 雕出，Fable 5.2 接手眼睛高光、透明鱼鳍、气泡和游动细节。

## Original post text

CLAUDE FABLE 5.2 IS DROPPED. FIRST THING I DID: HANDED IT A 3D PIRANHA THAT TAKES ITSELF APART.

this is Piranha P-7. sculpted with Claude Opus 5.5, finished by Fable 5.2 the day it came out

no 3D model, no Blender. every scale, tooth and rib is code.

how it's made:

1. ONE REFERENCE - SET THE LOOK
a silver sculpt: spiked dorsal crest, underbite, needle teeth, ringed eye

2. CLAUDE - SCULPT IT IN THREE.JS
scales and a lateral line, 47 teeth on two jaws, 6 spined fins, 24 ribs, a skull and a stomach

3. ONE SCRIPT - RUN THE SHOW
jaws open, bite, fins out, shell open, skeleton, stomach scan, frenzy, true colours

4. FABLE 5.2 - THE FINISH
glossy eyes with a catchlight, see-through fins, bubbles, a body that sways in the water

the result?

a 20-second teardown where the stomach scan finds a gold coin and a fishing hook, and the silver fish paints itself into a real red-bellied piranha

what should I make Fable 5.2 build from scratch?
