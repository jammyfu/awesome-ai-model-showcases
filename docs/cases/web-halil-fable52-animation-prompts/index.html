# Prompt · web-halil-fable52-animation-prompts

In a single HTML file, make a cinematic scene that plays by itself: [scene, e.g. a lighthouse on a rock on a stormy night]. [What moves: e.g. the beam turns, rain falls, waves hit the rocks, lightning flashes far away.] The camera pushes in very slowly. Colour: [e.g. cold blue night, warm yellow light]. Use Canvas or WebGL, no external files. Full screen, fit a vertical screen, seamless 12-second loop.
