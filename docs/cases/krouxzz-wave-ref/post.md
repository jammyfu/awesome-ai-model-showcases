## Original post text

OpenAI just dropped images 2.6. you can now generate GIFs directly in ChatGPT

How you can make your own 👇

→ Open ChatGPT
→ Describe what you want animated, or upload an image to use as a reference
→ Ask it to create a GIF. Try: "Make a looping GIF of this character waving."

images 2.6 lets you turn a prompt into an animation. Animate a character, make a reaction GIF, or turn a product image into a loop, even a rough sketch can become an animated character

developers get two new API models:

/GPT-Image-2.6 Flare generates images in as little as 6 seconds at low quality

/GPT-Image-2.6 Sunburst delivers higher quality and keeps details more consistent across edits at medium and high quality

the API also gets image markup for targeted edits, SVG exports, and a complexity setting to control how much planning goes into a request

images 2.6 is available globally in ChatGPT and Codex across all subscription tiers. Both models are live in the API

full anouncement is here: https://openai.com/index/introducing-images-2-6/
