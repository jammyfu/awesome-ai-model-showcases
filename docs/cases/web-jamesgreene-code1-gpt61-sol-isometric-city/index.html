# Prompt · web-jamesgreene-code1-gpt61-sol-isometric-city

Build one self-contained HTML file: inline CSS and JavaScript only, no libraries, no external files, no network requests. Show an animated isometric city block that goes from day to night and back in a 12-second loop: the sky changes colour, windows light up at dusk, cars with headlights drive along the streets, and a small clock in one corner shows the time of day. It starts on its own when the page loads, needs no input, and fills the browser window at any size.
