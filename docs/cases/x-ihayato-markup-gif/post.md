## Original post text

GPT Image 2.6が出たので、さっそく試してみました。

まず「丸を描いて直す」機能。

元の絵に赤丸と青丸を描いて
「赤丸にサンタ帽、青丸の本はプレゼントに」
と頼むだけ。

顔も髪飾りも服もそのままで、丸の中だけ描き変わりました。20秒ちょっと。

1回の編集、小さい素材であれば、劣化感もほとんどないですね！

もうひとつが、GIFアニメ。

キャラの絵を1枚渡して「まばたきして、ふわっと揺れて」と頼むと、そのキャラのまま動きます。

季節衣装の差分も、ちょっとした動く素材も、AIで一発です。

ゲームづくりがまたラクになりますね。

ほかにも

・SVG（ベクター）で書き出せる
・描く前に「どこまで考えるか」を選べる
・生成が約50%速い（OpenAI発表）

といった新機能が入っています。

コストもざっくりまとめました。

2.5と変わらず、low品質なら1枚4円程度！

2.5から純粋なアプデなので、2.5を使ってる方は、今後は2.6にするといいと思います。
