Prompt

# Prompt · x-financeyf5-fable52-bugatti-tourbillon

Build a modular, highly accurate, and realistic model of the Bugatti Tourbillon in Blender using these reference images. Make sure each part is complete and matches the blueprints and references provided, and is correctly shaped and textured. The gates should open and close, and the lights inside should be able to turn on and off, etc. Create a fully working model design.
Use subagents and critics to build and verify each part. Make sure it looks incredible and high-quality, with all materials and textures, and make a short 3D animation with music of it in a good environment, like a real car showcase, with moving pieces combining to become a car, camera shots of the exterior and interior, etc., after that.
