## Original post text

My favorite thing I built with Fable 5.2?

→ https://typed.page/

Inspired by (and integrated w) @rauchg's WebGL2 record player, this is a  fully functioning typewriter where you can:
- type or click out words
- set writing timers
- use whiteout and auto correct issues
- browse notecards of writing prompts
- type in a moody office, cozy train, scribble in a notebook, or print to your dot matrix printer
- follows your local time of day (or pick your vibe)
- saves pages locally, download as image or text

might make it into a real app
