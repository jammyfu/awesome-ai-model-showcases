## 每条有什么字段

不是表格，是重复的小结构：

- 标题：`序号｜一句话说明做了什么`
- 简介：谁做的、做了什么、大约用了多久（如果作者写了）
- 证据与边界：哪些是作者自述，公开素材能看到什么，哪些还不能外推
- 链接：`X 原帖` 是原作者帖；旁边常有项目页、团队汇总帖或论文。`查看原帖` 往往只是加粗文字，不是另一条 URL
- 封面图：文件名经常就是帖子 status id，图说写明是原帖录屏封面
- 部分条目嵌了 mp4（知识库自己传的文件，不是我们要再托管的那一份）
- 耗时、费用、提示轮次、代理数：没有单独字段，写在简介或证据里，而且只在原作者披露时才有

没有单独的「提示词」字段。简介是知识库的转述，不当作原提示词。
