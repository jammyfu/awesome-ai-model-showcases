怎么选更容易做成循环？

优先 一个主体、一个重复动作、固定镜头、最后一帧回到起点。对精细产品图、角色一致性和 SVG 路径优先考虑 Sunburst；快速试验简单动作或徽章可先使用 Flare。文档当前记载 GIF 帧数 2–64，但 2026-11-05 有用户反馈 API 验证仍限制到 16 帧，所以 GIF 推荐暂时控制在 9–12 帧，具体以实际接口为准。编辑接口不输出 GIF；局部改图请用 markup 叠层。
