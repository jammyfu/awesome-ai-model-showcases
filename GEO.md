# Project discovery facts

This file records a reviewable metadata proposal. It is not a GitHub or search-engine standard and does not guarantee indexing, traffic, or keyword ranking. Repository About and topics have not been changed by this README work.

## Identity and positioning

- Name: Awesome AI Model Showcases / AI 模型制作案例集.
- Reader outcome: find AI-made animations, interactive demos, and games, then trace the creator, source, available prompt, and recorded method.
- Type: independent community case archive; not a model API, benchmark, or certification service.
- Main action: [browse the gallery](https://jammyfu.github.io/awesome-ai-model-showcases/).
- Canonical repository: <https://github.com/jammyfu/awesome-ai-model-showcases>.
- Current counts and model labels: [generated catalog](docs/data/community-cases.json). Do not copy changing counts into static metadata.

## Suggested About and topics

Suggested About (97 characters):

> Source-linked AI model showcases: animations, interactive demos, games, prompts, creator credits.

Suggested topics, ordered by role rather than popularity:

Apply repository settings only with the owner's authorization. Avoid unverified model-release names, competitive rankings, popularity counts, duplicated keywords, and unsupported integrations.

## Fact boundaries

- Source model labels are claims, not independently verified provenance. Missing and partial prompts remain explicitly labeled.
- Five README/evidence locales are available, including Korean. The main catalog interface supports English and Simplified Chinese; the separately licensed large-preview gallery has English, Simplified Chinese, Traditional Chinese, Japanese and Korean pages.
- MIT applies to code and original project documentation, not third-party media or prompts. [Media rights](MEDIA_RIGHTS.md) defines exact publication permission.
- The homepage families, separate GPT Image archive, appendices, and pending items must remain distinct across README, metadata, and [llms.txt](llms.txt).
