# First public release checklist

1. Verify rights for each of the six initial GIFs. Remove or replace any items that rely on third-party photos, identifiable likenesses, copyrighted memes, or offensive text you cannot or do not want to publish. The code is ready independently of those media decisions.
2. Create the public repository named `awesome-ai-model-showcases` under `jammyfu`, with **no automatically generated README or license** (the project includes both).
3. Push the prepared git repository: `git remote add origin https://github.com/jammyfu/awesome-ai-model-showcases.git && git push -u origin main`.
4. In repository Settings → Pages → Build and deployment, select **GitHub Actions**.
5. Add the About description: `Curated GPT Image 2.6 animated GIF gallery — free AI GIF examples, memes, prompts and seamless loops.`
6. Add topics: `gpt-image-2-6`, `gpt-image`, `animated-gif`, `ai-gif`, `gif-generator`, `prompt-engineering`, `gif-gallery`, `openai`, `ai-animation`, `awesome-list`.
7. Verify Actions → Validate GIF gallery passes and Deploy GitHub Pages gallery succeeds. Only then publicly advertise the Pages link.
8. Post a few human-friendly GIF + prompt comparisons to social platforms, always linking back to their exact `prompts/*.md` source. Actual traction depends on content quality and referrals, not the repository name alone.
