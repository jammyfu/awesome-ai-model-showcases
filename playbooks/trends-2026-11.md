**Research date:** 2026-11-06（北京时间）; **launch date:** 2026-11-04. This is a qualitative curator's catalogue, **not** a quantified trend ranking, search-volume report, or claim that every prompt was run.

## Selection and scoring (editorial, NOT traffic numbers)

- **P1:** already demonstrated on a dated source and/or broadly reusable for memes, websites or product work.
- **P2:** useful but more complex action or less directly supported evidence; test before making claims about quality.
- **P3:** original exploratory visuals, not observed trends.
- `official`, `tested`, `community`, `concept` label provenance, **not** performance quality.
- `prompt_status`: `verbatim` = copied from a public page; `reconstructed` = authored in this repo; `empty` = source had no copyable prompt (do not invent one).
- Thumbnails are mixed: original previews already in this repository (unverified reference rights), original **SVG concept covers**, or `link_only` with an empty local asset. Concept covers are *not* GIF generations nor proof that prompts will work.
- **No third-party photos or GIFs were downloaded** for the 2026-11-06 expansion. OpenAI / Morphic / Nereo / Lightlyn / X media stay at the source URL.

## Reproducibility caveats

- Recommended model choice/frames/timing are starting hypotheses; outputs vary. There were no new API generation calls for these cards.
- On Nov 5 a developer reported a mismatch between guide (up to 64 frames) and API error on >16 frames: https://community.openai.com/t/gpt-image-2-6-gif-frame-limit-guide-says-64-api-enforces-16/1413021 . Conservative GIF recommendations here use <= 12 frames until this is reconciled.
- GPT Image 2.6 image generation endpoint supports GIF output; **image edit endpoint does not support GIF output** according to the official guide. Markup edits are stills.
- Before reuse, verify any third-party identity, photo, character, trademark or caption permissions; see [MEDIA_RIGHTS.md](../MEDIA_RIGHTS.md).
