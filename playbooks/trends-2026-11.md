## Selection and scoring (editorial, NOT traffic numbers)

- **P1:** already demonstrated on a dated source and/or broadly reusable for memes, websites or product work.
- **P2:** useful but more complex action or less directly supported evidence; test before making claims about quality.
- **P3:** original exploratory visuals, not observed trends.
- `official`, `tested`, `community`, `concept` label provenance, **not** performance quality.
- The 20 SVG/GIF thumbnails are mixed: original previews already in this repository (unverified reference rights), or original **SVG concept covers**. The concept covers are *not* GIF generations nor proof that prompts will work.
- All English prompt text is authored or paraphrased here. Reference links are included; **no third-party photos or GIFs have been downloaded or redistributed**.

## Reproducibility caveats

- Recommended model choice/frames/timing are starting hypotheses; outputs vary. There were no new API generation calls for these 20 cards in this collection update.
- On Nov 5 a developer reported a mismatch between guide (up to 64 frames) and API error on >16 frames: https://community.openai.com/t/gpt-image-2-6-gif-frame-limit-guide-says-64-api-enforces-16/1413021 . Conservative recommendations here use <= 12 frames until this is reconciled.
- GPT Image 2.6 image generation endpoint supports GIF output; **image edit endpoint does not support GIF output** according to the official guide. A user-supplied image may still work via supported ChatGPT functionality, but do not assume GIF edits work through the API image-edit endpoint.
- Before reuse, verify any third-party identity, photo, character, trademark or caption permissions; see [MEDIA_RIGHTS.md](../MEDIA_RIGHTS.md).
