# Agent guide

This repository is **Awesome AI Model Showcases** / **AI 模型制作案例集**: a community archive of public AI model GIF and animation cases, organized by model family. GPT Image 2.6 is one populated subsection. It is not a playbook showcase and not an Images API app.

## Loop files

- Current work: `CURRENT_PLAN.md`
- Long route: `MASTER_PLAN.md`
- Later work: `TODO_BACKLOG.md`
- Records: `docs/project-governance/`

## Verify

```bash
python3 tools/verify.py
```

`tools/verify.py` must use `sys.executable`. Do not call bare `python` from PATH. Prefer existing validators; do not add a second verify entry.

## Do not add

- `git-autosync-signal` (dramaforge/clippipeline only)
- heartbeat / LaunchAgent / `sync_or_queue.py` automation
- paid image generation
- SVG concept art as case results
- promo / 2.5 / multimodel / failure rows in the main catalog
- Invented prompts, authors, or source URLs

## Catalog shape

- Inventory is generated by `tools/write_community_catalog.py`
- Cases are grouped by **model family** (`meta.structure = model_family`)
- Empty family buckets stay empty until a real sourced case is added

## Media

User-requested local archive for GPT Image cases already ingested. New families default to source-link citation unless a documented grant allows local copy. License remains unknown otherwise. MIT covers source code only. Incremental ingest: `python3 tools/ingest_local_media.py`.
